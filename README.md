# ES HSE Android APK

هذا المشروع يحول تطبيق Base44 إلى تطبيق Android باستخدام WebView.

الرابط المضمّن:
https://es-hse-copy-1496a243.base44.app

## أسهل طريقة لبناء APK مجانًا

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع كل ملفات هذا المشروع.
3. افتح تبويب **Actions**.
4. شغّل **Build ES HSE APK** يدويًا.
5. بعد انتهاء البناء افتح نتيجة التشغيل (Run).
6. من قسم **Artifacts** نزّل `ES-HSE-debug`.
7. فك الضغط وستجد `app-debug.apk`.

هذا APK تجريبي/Debug مناسب للتثبيت المباشر. إذا أردت نشره كتطبيق إصدار نهائي أو تحديثه مستقبلًا، استخدم مفتاح توقيع Release خاصًا بك.
